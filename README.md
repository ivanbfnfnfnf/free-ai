# Arena IDE — бесплатный доступ к моделям LM Arena

GUI-агент + локальный OpenAI-совместимый прокси поверх **LM Arena** (arena.ai, бывший lmarena.ai).
Модели арены (gemini, gpt, claude, deepseek, kimi, grok, qwen и др.) доступны бесплатно — как на сайте, Direct-режимом (одна выбранная модель).

> **⚠️ Дисклеймер.** Проект не связан с LM Arena и создан в образовательных целях для личного
> использования. Автоматизация доступа к сайту может нарушать его условия использования —
> используйте на свой риск: возможны ограничения аккаунта или изменения API, которые сломают
> инструмент. Никакие данные аккаунта не собираются и никуда не отправляются: всё работает
> локально, через ваш собственный браузер.

## Быстрый старт без Python (готовые exe)

В папке `exe\` лежат собранные программы:

```
exe\ArenaIDE.exe    ← IDE с интерфейсом + встроенный прокси (двойной клик — и всё)
exe\ArenaAPI.exe    ← только прокси (OpenAI-совместимый API на http://127.0.0.1:8081/v1)
```

1. Запустите `ArenaIDE.exe`.
2. При первом запуске откроется окно браузера — **войдите в arena.ai один раз** (или пользуйтесь анонимно).
3. Готово: пишите запросы в чат, модель и «Новый чат» — в панели справа.

Свой порт/модель можно задать в `.env` рядом с exe (образец — `.env.example`).

## Установка из исходников

1. Нужен Python 3.10+ и любой из браузеров: Chrome / Edge / Brave.
2. Зависимости:
   ```
   pip install websocket-client
   ```
3. Скопируйте `.env.example` в `.env` (настройки уже готовы).

## Как это работает

```
IDE (arena_gui.py) ──HTTP──> Arena API (arena_api.py, localhost:8081/v1)
                                   │  (CDP — DevTools Protocol)
                                   ▼
                        Chrome с профилем ArenaIDE
                        (реальная страница arena.ai)
                                   │  fetch из страницы
                                   ▼
                        arena.ai /nextjs-api/stream/create-evaluation
                        (Direct-режим, выбранная модель)
```

Запросы уходят **из реальной страницы arena.ai** в управляемом Chrome, поэтому:

- Cloudflare и reCAPTCHA Enterprise проходят автоматически;
- сессия входа живёт в отдельном профиле `%LOCALAPPDATA%\ArenaIDE\chrome-profile`;
- reCAPTCHA-токен одноразовый — минтится свежий на каждый запрос через `grecaptcha`
  прямо на странице;
- стрим ответа арены (`a0:"текст"`, `ag:"мысли"`, `ad:{finishReason}`) превращается
  в OpenAI-стрим (`content` / `reasoning_content` / `finish_reason`).

## Первый запуск (вход в аккаунт — один раз)

```
START_API.bat
```
или вручную:
```
python arena_api.py --setup    # откроется окно браузера — войдите в arena.ai
python arena_api.py            # запустится сервер на http://127.0.0.1:8081/v1
```
Проверка: откройте `http://127.0.0.1:8081/` — там статус (браузер, вход, модели).

> Можно и без входа в аккаунт (анонимно), но с аккаунтом лимиты выше.

## Запуск IDE (GUI)

```
START_IDE.bat
```
или вручную:
```
python arena_gui.py
```

GUI-IDE (tkinter, без зависимостей):

- окно чата со **стримом ответа** («мышление» модели — приглушённым курсивом);
- **переключение моделей** — выпадающий список сверху (кнопка «Обновить» тянет актуальный список с арены);
- инструменты агента: `read_file`, `create_file`, `edit_file`, `list_dir`, `glob_files`, `search_content`, `run_shell` (опасные команды — с подтверждением);
- Enter — отправить, Shift+Enter — новая строка, кнопка «Стоп» прерывает ответ;
- **«Новый чат»** — очищает диалог; следующее сообщение начнёт **новую сессию на арене**. Обычные запросы продолжают текущую сессию (контекст хранится на стороне арены, история заново не отправляется);
- сессии: «Сохранить» / «Загрузить» (папка `~/.arena_sessions`);
- прокси запускается автоматически, если ещё не запущен (статус в правом верхнем углу).

Консольная версия тоже осталась: `python arena_cli.py` (та же логика, терминальный интерфейс).

## Прочие команды arena_api.py

```
python arena_api.py --models     # список моделей (в консоль)
python arena_api.py --selftest   # проверка сервера (без реального запроса к чату)
python arena_api.py --selftest --full   # + реальный короткий чат-запрос
```

## Скомпилировать в EXE (ArenaIDE.exe)

После того как Python-версия проверена и улучшена:

```
pip install pyinstaller
BUILD_EXE.bat        # соберёт dist\ArenaIDE.exe и dist\ArenaAPI.exe
```
`ArenaIDE.exe` — «всё в одном» (сервер + IDE). `.env` кладите рядом с exe.

## Ограничения

- Лимиты арены: ~1800 запросов / 5 минут на аккаунт (429 обрабатывается с Retry-After).
- Vision-картинки в Direct-чате пока не передаются (только текст).
- Если Cloudflare показывает «Just a moment» — пройдите проверку в окне браузера арены вручную.
- reCAPTCHA-токен живёт ~115 с, поэтому перед каждым запросом минтится свежий.
